# TRM-Live-UI

中文 | [English](README_en.md) | [日本語](README_ja.md)

图灵镜的直播界面，放进 OBS 使用。可以在控制面板里实时修改文字，切换开播前、稍后回来、即将下播等状态，并保存预设。

## 开始使用

需要先安装 [Node.js](https://nodejs.org/)。双击 `start.bat` 启动，然后按 [使用说明](docs/guide.zh-CN.md) 在 OBS 里设置。
