# TRM-Live-UI

[中文](README.md) | English | [日本語](README_ja.md)

A live streaming overlay for Turing Mirror, made for OBS. Use the control panel to change text in real time, switch between scenes such as starting, be right back and ending, and save presets.

## Getting started

Install [Node.js](https://nodejs.org/) first. Double-click `start.bat` to start, then follow the [guide](docs/guide.en.md) to set up OBS.
