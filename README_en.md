# TRM-Live-UI

[中文](README.md) | English | [日本語](README_ja.md)

A live streaming overlay for Turing Mirror, made for OBS. Use the control panel to change text in real time, switch between scenes such as starting, be right back and ending, save presets, and switch between UI packs of different styles in the UI library.

## Getting started

Install [Node.js](https://nodejs.org/) 20 or later first. Double-click `start.bat` to start, then follow the [guide](docs/guide.en.md) to set up OBS.

## Making UI packs and contributing

See the [developer guide](docs/develop.en.md).
