# TRM-Live-UI 使い方

[中文](guide.zh-CN.md) | [English](guide.en.md) | 日本語

## 起動

`start.bat` をダブルクリックします。ウィンドウに次の 2 つのアドレスが表示されます。

- 配信画面：`http://127.0.0.1:5170/overlay`
- コントロールパネル：`http://127.0.0.1:5170/panel`

配信中はこのウィンドウを閉じないでください。

## OBS の設定

1. 「ブラウザ」ソースを追加し、URL に配信画面のアドレスを入力します。幅は 1920、高さは 1080 にします。
2. 「ドック → カスタムブラウザドック」にコントロールパネルのアドレスを追加すると、OBS の中で内容を編集できます。
3. ソースを上から次の順に並べます。
   - Live2D モデル（VTube Studio）。画面全体に表示します。
   - 配信画面（このプロジェクト）
   - ゲームまたは画面キャプチャ。中央の切り抜き部分に合わせます。

## 中央の画面を合わせる

OBS でゲームまたは画面キャプチャのソースを選び、Ctrl + E で「変換の編集」を開きます。次の表のとおりに入力します（OBS 32 の場合）。

| 項目 | 欄 | 値 |
|---|---|---|
| 位置 | X、Y | 20、124 |
| 位置 | 配置 | 左上 |
| 大きさ | 幅、高さ | 変更不要です。境界に合わせて自動で変わります。 |
| 境界 | 境界の種類 | 外側に合わせる |
| 境界 | 幅、高さ | 1480、836 |
| 境界 | 境界内の配置 | 中央 |
| 境界 | 境界にクロップ | チェックを入れる |

この値は `config/settings.json` の `capture` 領域の x、y、w、h に、各辺 4 ピクセルを足したものです。はみ出た部分が配信画面の縁の下に隠れるので、細い黒い線が出ません。レイアウトを変えたときは「x − 4、y − 4、w + 8、h + 8」で入力し直します。

「外側に合わせる」と「境界にクロップ」を使うと、画面が領域全体を覆い、はみ出た部分は切り取られます。黒い帯は出ません。画面全体を見せたいときは「内側に合わせる」を選びます。縦横比が合わない場合は黒い帯が出ます。

ウィンドウキャプチャにタイトルバーや枠が入る場合は、同じウィンドウの「クロップ」で取り除くピクセル数を入力します。

## 内容の編集

コントロールパネルで文字を編集し、「更新到直播」（更新）を押すか、Ctrl + Enter を押します。配信画面はすぐに変わり、再読み込みは不要です。

内容は `config/content.json` に保存され、このファイルを直接編集することもできます。初回起動時に `config/content.default.json` から作られます。このファイルは手元のパソコンだけに残り、リポジトリにはコミットされません。

## シーン

コントロールパネルの一番上で 4 つのシーンを切り替えられます。押すとすぐに反映されます。

| シーン | 画面 |
|---|---|
| 配信中 | 通常のレイアウト |
| 配信開始前 | 幾何学タイルが波のように回転します |
| 少々お待ちください | 小さな図形が順番に跳ねます |
| まもなく終了 | 太陽がゆっくり沈み、星がまたたきます |

後の 3 つのシーンでは、上部のバーはそのまま残り、その下が待機画面に変わります。待機画面の文字はコントロールパネルで編集します。カウントダウン欄に 21:00 のような時刻を入れるとカウントダウンが表示されます。空欄にすると表示されません。

待機画面の右側には、Live2D モデル用に 420 ピクセルの空きがあります。この幅は `config/settings.json` の該当する領域の `reserve` で変更できます。アニメーションの色は `theme.palette` にあります。

シーンを追加するには、`scenes` に項目を足し、`regions` に `screen` 種類の領域を足します。`options.scene` でシーンと結び付け、`options.animation` でアニメーションを選びます。アニメーションを追加するには `public/js/animations.js` を編集します。

## プリセット

プリセット欄はシーンの下にあります。

- **保存**：名前を入力し、「保存当前内容」（現在の内容を保存）を押します。同じ名前のプリセットは上書きされます。
- **読み込み**：一覧からプリセットを選び、「载入」（読み込み）を押します。内容が下の入力欄に入ります。「更新到直播」（更新）を押すと配信画面に反映されます。
- **削除**：プリセットを選び、「删除」（削除）を押します。

プリセットは `config/presets/` に 1 つずつファイルとして保存されるので、そのまま他の人に渡せます。このフォルダも手元のパソコンだけに残ります。

## レイアウトと色の変更

`config/settings.json` を編集します。保存すると配信画面が更新されます。

- `theme.fonts`：フォント。`title` は見出し用、`body` は本文用です。
- `theme.colors`：色
- `theme.sizes`：文字の大きさ
- `theme.radius`：角の丸み
- `ticker`：ティッカーの速さ（1 秒あたりのピクセル数）
- `regions`：各領域の位置（x、y）と大きさ（w、h）。単位はピクセルです。`"options": { "autoHeight": true }` を付けると高さが内容に合わせて変わり、h は最大の高さになります。お知らせ欄は初期状態でこの設定です。
- `server.port`：ポート番号。変更後は再起動が必要です。

## 領域の種類

| 種類 | 用途 |
|---|---|
| `hole` | 切り抜き。下の OBS ソースが見えます |
| `title` | バッジ、番組名、今回のタイトル |
| `status` | 状態の文字。時計も表示できます |
| `notice` | お知らせ |
| `ticker` | 流れる文字 |
| `screen` | 待機画面。対応するシーンでだけ表示されます |

領域の種類を追加するには `public/js/kinds.js` を編集します。
