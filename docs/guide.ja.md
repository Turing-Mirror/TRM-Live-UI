# TRM Live UI 使い方

[中文](guide.zh-CN.md) | [English](guide.en.md) | 日本語

独自の UI パックを作る場合や開発に参加する場合は、[開発ガイド](develop.ja.md) をご覧ください。

## 起動

[Node.js](https://nodejs.org/)（20 以降）をインストールし、`start.bat` をダブルクリックします。ウィンドウに次の 2 つのアドレスが表示されます。

- 配信画面：`http://127.0.0.1:5170/overlay`
- コントロールパネル：`http://127.0.0.1:5170/panel`

配信中はこのウィンドウを閉じないでください。

## OBS の設定

1. 「ブラウザ」ソースを追加し、URL に配信画面のアドレスを入力します。幅は 1920、高さは 1080 にします。
2. コントロールパネルをブラウザで開きます。「ドック → カスタムブラウザドック」に追加すると、OBS の中で操作できます。
3. ソースを上から次の順に並べます。
   - Live2D モデル（VTube Studio）。画面全体に表示します。
   - 配信画面（このプログラム）
   - ゲームまたは画面キャプチャ。中央の切り抜き部分に合わせます。

## 中央の画面を合わせる

OBS でゲームまたは画面キャプチャのソースを選び、Ctrl + E で「変換の編集」を開きます。次の表のとおりに入力します（OBS 32 と既定の UI パックの場合）。

| 項目 | 欄 | 値 |
|---|---|---|
| 位置 | X、Y | 20、124 |
| 位置 | 配置 | 左上 |
| 大きさ | 幅、高さ | 変更不要です。境界に合わせて自動で変わります。 |
| 境界 | 境界の種類 | 外側に合わせる |
| 境界 | バウンディングボックスの幅、高さ | 1480、836 |
| 境界 | 境界内の配置 | 中央 |
| 境界 | 境界にクロップ | チェックを入れる |

この値は UI パックの `pack.json` にある `capture` 領域の x、y、w、h に、各辺 4 ピクセルを足したものです。はみ出た部分が縁の下に隠れるので、細い黒い線が出ません。レイアウトを変えたときは「x − 4、y − 4、w + 8、h + 8」で入力し直します。

「外側に合わせる」と「境界にクロップ」を使うと、画面が領域全体を覆い、はみ出た部分は切り取られます。黒い帯は出ません。画面全体を見せたいときは「内側に合わせる」を選びます。縦横比が合わない場合は黒い帯が出ます。

ウィンドウキャプチャにタイトルバーや枠が入る場合は、同じウィンドウの「クロップ」で取り除くピクセル数を入力します。

## コントロールパネル

左側のサイドバーには、配信、内容、プリセット、UI ライブラリ、設定の 5 つのページがあります。その下にすべてのシーンが並び、押すとそのシーンに切り替わります。OBS のドックのように幅が狭い場合、サイドバーはアイコンだけの列になります。

| ページ | 用途 |
|---|---|
| 配信 | シーンの切り替えとライブプレビュー |
| 内容 | 配信画面と待機画面の文字の編集 |
| プリセット | プリセットの保存、読み込み、削除 |
| UI ライブラリ | UI パックの切り替え、読み込み、書き出し、削除 |
| 設定 | 表示言語、OBS で使うアドレス、バージョン情報 |

### 内容の編集

「内容」ページで文字を編集し、「配信に反映」を押すか、Ctrl + Enter を押します。未反映の変更がある節は見出しの横に小さな点が付き、サイドバーの「内容」にも付きます。「変更を取り消す」を押すと、配信画面に今表示されている状態に戻ります。

### シーン

押すとすぐに反映されます。Alt + 数字キーでも切り替えられます。既定の UI パックには 4 つのシーンがあります。

| シーン | 画面 |
|---|---|
| 配信中 | 通常のレイアウト |
| 配信開始前 | 幾何学タイルが波のように回転します |
| 少々お待ちください | 小さな図形が順番に跳ねます |
| まもなく終了 | 太陽がゆっくり沈み、星がまたたきます |

待機画面に切り替えると、幕が左から右へ閉じてから、文字とアニメーションが表示されます。待機画面どうしで切り替えるときは幕が閉じたままで中身だけが変わるため、下の配信内容は見えません。配信中に戻すと、幕は右へ開きます。

「カウントダウンの時刻」に 21:00 のような時刻を入れるとカウントダウンが表示されます。空欄にすると表示されません。

### プリセット

- **保存**：名前を入力して「保存」を押します。「内容」ページの現在の文字が保存されます。同じ名前のプリセットがある場合は先に確認します。
- **読み込み**：内容が「内容」ページに入ります。「配信に反映」を押すと配信画面に表示されます。
- **削除**：プリセットの横の「削除」を押します。

プリセットには現在のシーンは含まれません。UI パックごとに別のプリセットを持ちます。

### UI ライブラリ

すべての UI パックを一覧表示し、作成に使われたプログラムのバージョンを示します。使えないパックには、より新しいバージョンが必要などの理由が表示されます。

- **使う**：この UI に切り替えます。配信画面はすぐに変わります。
- **読み込み**：UI パックの zip ファイルを選びます。読み込む前にパックの名前とバージョンが表示されます。スクリプトを含むパックの場合は注意が表示されます。信頼できる提供元のパックだけを読み込んでください。
- **書き出し**：UI パックを zip ファイルとして保存します。そのまま他の人に渡せます。
- **削除**：削除できるのは読み込んだパックだけで、内蔵のパックは削除できません。削除したパックは `data/backups/` に移され、内容とプリセットは残ります。

## データの保存場所

| 場所 | 内容 |
|---|---|
| `data/content/` | UI パックごとの文字の内容と現在のシーン |
| `data/presets/` | UI パックごとのプリセット |
| `data/packs/` | 読み込んだ UI パック |
| `data/config.json` | 変更した設定（表示言語、使用中の UI パック、ポートなど） |
| `data/backups/` | 壊れたファイルや旧バージョンのデータのバックアップ |

`data/` は手元のパソコンだけに残り、リポジトリにはコミットされません。旧バージョンが `config/` に保存していた内容は、新しいバージョンの初回起動時に自動でここへ移されます。

ポートを変えるには、`data/config.json` に次のように書きます。

```json
{ "server": { "port": 5180 } }
```

書き換えたらプログラムを再起動してください。
