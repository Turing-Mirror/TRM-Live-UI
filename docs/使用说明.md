# 图灵镜直播模板 使用说明

## 启动

双击 `start.bat`。窗口里会显示两个地址：

- 直播画面：`http://127.0.0.1:5170/overlay`
- 控制面板：`http://127.0.0.1:5170/panel`

直播期间不要关闭这个窗口。

## 在 OBS 里设置

1. 添加“浏览器”来源，网址填直播画面地址，宽 1920、高 1080。
2. 在“停靠窗口 → 自定义浏览器停靠窗口”里添加控制面板地址，就可以在 OBS 里直接修改内容。
3. 来源从上到下按这个顺序摆放：
   - Live2D 模型（VTube Studio），铺满整个画面
   - 直播画面（本模板）
   - 游戏或屏幕画面，对准中间的镂空区域

## 对齐中间的画面

在 OBS 里选中游戏或屏幕画面的来源，按 Ctrl + E 打开“编辑变换”，按下表填写（以 OBS 32 为准）：

| 区块 | 项目 | 填写 |
|---|---|---|
| 位置 | X、Y | 20、124 |
| 位置 | 对齐 | 左上 |
| 大小 | 宽度、高度 | 不用改，会跟着边界自动变化 |
| 边界 | 下拉框 | 覆盖 |
| 边界 | 宽度、高度 | 1480、836 |
| 边界 | 对齐 | 中间 |
| 边界 | 裁剪边界 | 勾选 |

这组数字来自 `config/settings.json` 里 `capture` 区域的 x、y、w、h，并且每边多出 4 像素，让画面压在模板边缘下面，避免露出细黑线。改了布局以后，按“x − 4、y − 4、w + 8、h + 8”重新填写。

选“覆盖”并勾选“裁剪边界”时，画面会铺满整个区域，超出的部分被切掉，不会出现黑边。如果想看到完整画面，可以改成“适应”，比例不合时会留出黑边。

窗口采集带有标题栏或边框时，可以在同一个窗口里的“裁剪”中填写要去掉的像素。

## 修改内容

在控制面板里改好文字后，点击“更新到直播”，或者按 Ctrl + Enter。画面会马上变化，不需要刷新。

内容保存在 `config/content.json`，也可以直接修改这个文件。

## 预设

控制面板最上方是预设区：

- **保存**：填写名称后，点击“保存当前内容”。同名预设会被覆盖。
- **载入**：在下拉框里选好预设，点击“载入”。内容会填进下方的输入框，点击“更新到直播”后才会显示到画面上。
- **删除**：选好预设，点击“删除”。

预设保存在 `config/presets/` 文件夹里，每个预设是一个文件，可以直接复制给别人。

## 修改布局和颜色

打开 `config/settings.json` 修改，保存后画面会自动更新。

- `theme.fonts`：字体，`title` 用于标题，`body` 用于正文
- `theme.colors`：各处颜色
- `theme.sizes`：字号
- `theme.radius`：圆角大小
- `ticker`：滚动字幕的速度（每秒移动的像素）
- `regions`：每个区域的位置（x、y）和大小（w、h），单位是像素。加上 `"options": { "autoHeight": true }` 后，高度会跟着内容变化，h 是最大高度，公告区默认是这样
- `server.port`：端口，改完需要重新启动

## 区域类型

| 类型 | 用途 |
|---|---|
| `hole` | 镂空，透出 OBS 里的画面 |
| `title` | 角标、节目名和本期标题 |
| `status` | 状态文字，可显示时钟 |
| `notice` | 公告 |
| `ticker` | 滚动字幕 |

要增加新的区域类型，请在 `public/js/kinds.js` 里添加。
