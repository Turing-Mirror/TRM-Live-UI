# 图灵镜直播模板 使用说明

## 启动

双击 `start.bat`。窗口里会显示两个地址：

- 直播画面：`http://127.0.0.1:5170/overlay`
- 控制面板：`http://127.0.0.1:5170/panel`

直播期间不要关闭这个窗口。

## 在 OBS 里设置

1. 添加“浏览器”来源，网址填直播画面地址，宽 1920、高 1080。
2. 在“停靠窗口 → 自定义浏览器停靠窗口”里添加控制面板地址，就可以在 OBS 里直接修改内容。
3. 来源从上到下按这个顺序摆放：
   - Live2D 模型（VTube Studio），铺满整个画面
   - 直播画面（本模板）
   - 游戏或屏幕画面，对准中间的镂空区域

## 修改内容

在控制面板里改好文字后，点击“更新到直播”，或者按 Ctrl + Enter。画面会马上变化，不需要刷新。

内容保存在 `config/content.json`，也可以直接修改这个文件。

## 修改布局和颜色

打开 `config/settings.json` 修改，保存后画面会自动更新。

- `theme.fonts`：字体，`title` 用于标题，`body` 用于正文
- `theme.colors`：各处颜色
- `theme.sizes`：字号
- `theme.radius`：圆角大小
- `ticker`：滚动字幕的速度（每秒移动的像素）
- `regions`：每个区域的位置（x、y）和大小（w、h），单位是像素
- `server.port`：端口，改完需要重新启动

## 区域类型

| 类型 | 用途 |
|---|---|
| `hole` | 镂空，透出 OBS 里的画面 |
| `title` | 角标、节目名和本期标题 |
| `status` | 状态文字，可显示时钟 |
| `notice` | 公告 |
| `ticker` | 滚动字幕 |

要增加新的区域类型，请在 `public/js/kinds.js` 里添加。
