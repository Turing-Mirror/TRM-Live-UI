# TRM Live UI 使用说明

中文 | [English](guide.en.md) | [日本語](guide.ja.md)

想制作自己的 UI 包或参与开发，请看 [开发说明](develop.zh-CN.md)。

## 启动

先安装 [Node.js](https://nodejs.org/)（20 或更新版本），然后双击 `start.bat`。窗口里会显示两个地址：

- 直播画面：`http://127.0.0.1:5170/overlay`
- 控制面板：`http://127.0.0.1:5170/panel`

直播期间不要关闭这个窗口。

## 在 OBS 里设置

1. 添加“浏览器”来源，网址填直播画面地址，宽 1920、高 1080。
2. 用浏览器打开控制面板。也可以在“停靠窗口 → 自定义浏览器停靠窗口”里添加控制面板地址，在 OBS 里直接操作。
3. 来源从上到下按这个顺序摆放：
   - Live2D 模型（VTube Studio），铺满整个画面
   - 直播画面（本程序）
   - 游戏或屏幕画面，对准中间的镂空区域

## 对齐中间的画面

在 OBS 里选中游戏或屏幕画面的来源，按 Ctrl + E 打开“编辑变换”，按下表填写（以 OBS 32 和默认 UI 包为准）：

| 区块 | 项目 | 填写 |
|---|---|---|
| 位置 | X、Y | 20、124 |
| 位置 | 对齐 | 顶部左对齐 |
| 大小 | 宽度、高度 | 不用改，会跟着边界自动变化 |
| 边界 | 边界类型 | 覆盖 |
| 边界 | 宽度、高度 | 1480、836 |
| 边界 | 边界对齐 | 居中对齐 |
| 边界 | 裁剪边界 | 勾选 |

这组数字来自 UI 包 `pack.json` 里 `capture` 区域的 x、y、w、h，并且每边多出 4 像素，让画面压在边缘下面，避免露出细黑线。换了布局以后，按“x − 4、y − 4、w + 8、h + 8”重新填写。

选“覆盖”并勾选“裁剪边界”时，画面会铺满整个区域，超出的部分被切掉，不会出现黑边。如果想看到完整画面，可以改成“适应”，比例不合时会留出黑边。

窗口采集带有标题栏或边框时，可以在同一个窗口里的“裁剪”中填写要去掉的像素。

## 控制面板

左侧是状态、预设和界面库，右侧是实时预览和内容。顶栏可以切换界面语言。

### 修改内容

在右侧改好文字后，点击“更新到直播”，或者按 Ctrl + Enter。改过但还没更新的卡片会标出来。

### 状态

点一下立即生效，也可以按 Alt + 数字键。默认 UI 包有四种状态：

| 状态 | 画面 |
|---|---|
| 直播中 | 正常画面 |
| 开播前 | 几何拼块轮流旋转 |
| 稍后回来 | 一排小图形轮流蹦跳 |
| 即将下播 | 太阳慢慢落下，星星闪烁 |

切到等待画面时，幕布从左向右合上，再显示文字和动画。在几种等待画面之间切换时，幕布一直合着，只换里面的内容，下面的直播画面不会露出来。切回直播中时，幕布向右收起。

“倒计时到”填写时间（如 21:00）后会显示倒计时，留空则不显示。

### 预设

- **保存**：填写名称后点击“保存”，保存的是右侧现在的文字。同名预设会被覆盖。
- **载入**：内容会填进右侧，点击“更新到直播”后才会显示到画面上。
- **删除**：点击预设旁的“删除”。

预设不包含当前状态。每个 UI 包各有一组预设。

### 界面库

列出所有 UI 包，并标出制作时用的程序版本。无法使用的包会写明原因，例如需要更新的程序版本。

- **使用**：换成这套界面，直播画面马上跟着变。
- **导入**：选择一个 UI 包的 zip 文件。导入前会显示包的名称和版本；包里带脚本时会特别提醒，请只导入你信任的来源。
- **导出**：把 UI 包存成一个 zip 文件，可以直接发给别人。
- **删除**：只能删除导入的包，程序自带的包不能删除。删除的包会移到 `data/backups/`，内容和预设保留。

## 数据保存在哪里

| 位置 | 内容 |
|---|---|
| `data/content/` | 每个 UI 包的文字内容和当前状态 |
| `data/presets/` | 每个 UI 包的预设 |
| `data/packs/` | 导入的 UI 包 |
| `data/config.json` | 你改过的设置，如界面语言、正在使用的 UI 包、端口 |
| `data/backups/` | 损坏文件和旧版数据的备份 |

`data/` 只留在本机，不会提交到仓库。旧版本放在 `config/` 下的内容，第一次启动新版本时会自动搬过来。

要换端口，在 `data/config.json` 里写入：

```json
{ "server": { "port": 5180 } }
```

改完重新启动即可。
