# TRM-Live-UI

[中文](README.md) | [English](README_en.md) | 日本語

Turing Mirror（图灵镜）の配信用オーバーレイです。OBS で使います。コントロールパネルで文字をリアルタイムに変更し、配信開始前、少々お待ちください、まもなく終了などのシーンを切り替え、プリセットを保存し、UI ライブラリでスタイルの異なる UI パックを切り替えられます。

## はじめに

先に [Node.js](https://nodejs.org/)（20 以降）をインストールしてください。`start.bat` をダブルクリックして起動し、[使い方](docs/guide.ja.md) に沿って OBS を設定します。

## UI パックの作成と開発への参加

[開発ガイド](docs/develop.ja.md) をご覧ください。
